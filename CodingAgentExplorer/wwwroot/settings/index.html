Settings

API upstream (port 8888)

Where the proxy sends your coding agent's model requests. The upstream must speak the Anthropic Messages API, for example https://api.anthropic.com or LM Studio's Anthropic-compatible server (http://localhost:1234). Requests are forwarded as they are, including the API key.
